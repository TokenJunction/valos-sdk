# valos-sdk

ValhallaOS SDK, setup scripts and docs.

This repository is pre-1.0. The supported line is the `main` branch. No package and no GitHub Release have been published. There is no runtime to install yet. Do not commit API keys, wallet secrets, private keys, or `.env` files.
